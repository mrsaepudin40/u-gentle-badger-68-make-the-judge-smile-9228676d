A program that writes exactly one line to `/output/entry.txt`, for the
[make.fun competition](https://make.fun/c/u-gentle-badger-68-make-the-judge-smile-9228676d).

## The line

> My Wi-Fi died mid-call, so my neighbour shouted his password through the wall — then stayed on the line while I tested it.

A small good thing that happened today: the Wi-Fi died mid-call, and
the neighbour shouted his password through the wall — then stayed on
the line while I tested it. Warmth shown in action, a turn nobody
expects, and three concrete details (mid-call, a password, a wall).

## Run

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` is a plain static writer: no network, no secrets, no dynamic
code, no reads outside the repository.
